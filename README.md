# Simulation Visualizer

## Overview

Simulation Visualizer is the final module in the Scientific Computing - Simulation Pipeline project to be executed when the pipeline runs. As its name suggests, this module encapsulates all visualization-related logic, which is currently divided into two parts: the setup component, implemented in C++, and the visualization component, implemented in Python. As part of the simulation pipeline, this module also consumes simulation data generated by upstream modules, specifically from the Multi-Physics Solver module.

## Implemented Strategies

- [Matplotlib Visualization](https://adjoining-sing-847.notion.site/Matplotlib-Visualization-3ae4793fb41a80279b3fe0d0e07bd97f)

    As the name suggests, this strategy use Matplotlib as the primary Python package for visualizing simulation data. With this strategy, two plots are generated: a 3D scatter plot and a heat map. In addition to Matplotlib, this strategy uses two other Python packages: Numpy for handling the simulation data internally and h5py for reading the simulation data generated by upstream modules.

## Features

- [Visualizer Set-Up](https://adjoining-sing-847.notion.site/Visualizer-Setup-3b04793fb41a8094aba0f58ba71d0b21)

    To visualize the simulation data, users need to specify the area to be visualized and the source of the simulation data. To facilitate this process, this module presents a series of prompts through the CLI at the beginning of its execution, where the users can provide the required configurations. Later, the provided responses are then used as the basis for configuring the visualizer and are also appended to the existing zone data that have contributed by upstream modules. 

- [GIF Creation](https://adjoining-sing-847.notion.site/GIF-Creation-3ae4793fb41a809694b8d685d9945727)

    Considering that the simulation data may need to be analyzed at a later time, it is important to have a mechanism for preserving the visualization result in a persistent format. To address that need, this module provides a GIF export feature that automatically generates a GIF containing the visualization results whenever this module is executed.

- [I/O File Mapping Export](https://adjoining-sing-847.notion.site/Execution-Report-3ae4793fb41a80b8a893d3c1485269d6)

    After the visualizer has been configured, this module consumes the selected source files which contain the data to be visualized and generates output files with one-to-one mapping to the corresponding source files. To record this mapping, this module will export the information to the the execution report. With this feature in place, users can refer to the report when they need to identify the relationship between the source files and their corresponding visualization output files.

## Building the Module

- Dependencies

    - hdf5 (c++ package, managed by shared lib vcpkg)
    - gtest (c++ package, managed by shared lib vcpkg)
    - libxml2 (c++ package, managed by shared lib vcpkg)
    - nlohmann-json (c++ package, managed by shared lib vcpkg)
    - xdmf 3.0.0 (c++ package, built manually using cmake in shared lib)
    - numpy (python package, managed by pip)
    - matplotlib (python package, managed by pip)
    - h5py (python package, managed by pip)

- How to Build?

    a. Have cmake and ninja build system
    b. Add CMakeUserPresets.json if it is needed
    c. Add VCPKG_ROOT as env variable and set it to the root of your vcpkg directory
    d. Generate the project using cmake
    e. Build the executable using ninja

## Limitations

- The visualizer currently only supports the visualization of a plane zone.
- As for now, this module only supports XDMF/HDF5 as its input and output file formats. However, the module's architecture has been designed to accommodate other file formats in the future.
